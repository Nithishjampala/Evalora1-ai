Before first use

Create a Private Vercel Blob store and connect it to this Vercel project. Add the Blob store's BLOB_READ_WRITE_TOKEN to the project's environment variables if Vercel has not added it automatically. Also configure Gemini and Google service-account credentials.

The previous Gradio Video Analyzer is not included in this Vercel build. This deployment implements the four-phase Project Evaluation workflow and its Google Sheets output.
