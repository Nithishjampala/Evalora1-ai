Upload evaluation files

Upload all four phase guidelines and the student Excel sheet. Student phase links must be Google Drive links accessible to the configured service account. Empty phase links are skipped.

The Excel sheet should include student name, project ID/name (optional), and columns containing Drive links for Ideation, Design, Build and Demo.

Google Sheets destination

Each completed phase is appended to the Evaluation History tab with the 11 requested columns. Existing rows are retained.
